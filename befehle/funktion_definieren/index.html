Eine der wichtigsten Grundlagen ist das Definieren von Funktionen.

Im Calculator kannst du eine Funktion mit folgendem Befehl festlegen:

Bestandteile

  • : Name der Funktion und Variable

Damit wird die Funktion im CAS gespeichert.

Das := ist wichtig!

Wenn wir Funktionen per Hand aufschreiben, dass tun wir dies in etwas so: Dabei lassen wir meistens weg, dass wir die Funktion überhaupt erst definieren müssen. Unser CAS macht da allerdings einen großen Unterscheid draus.

  • := → Definition einer Funktion
  • = → Vergleich / Gleichung

Verwende daher zum Definieren immer :=
